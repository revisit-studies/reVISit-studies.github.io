# umux

The Usability Metric for User Experience (UMUX) is a short, standardized usability questionnaire developed as a concise and conceptually similar alternative to the System Usability Scale (SUS). It includes four statements designed to assess the perceived effectiveness, efficiency, and satisfaction of a system.

## Reference

:::note[Reference]
K. Finstad, “The usability metric for user experience,” Interacting with Computers, vol. 22, no. 5, pp. 323–327, 2010.
:::

DOI: [10.1016/j.intcom.2010.04.004](https://dx.doi.org/10.1016/j.intcom.2010.04.004)
